# ASTRA v1.2 구현·검증 보고서

작성일: 2026-09-17. 대상은 `astra-dashboard-v12/` 작업 사본입니다. 기존 소스는 그대로 보존하고 새 UI와 권한 서버를 추가했습니다.

## 검증 결과

- **신규 서버 통합 검사 5개 테스트 통과.** 내부적으로 10개 계정 전체, 회사 문서 41개에 대한 계정별 허용/거부, 다른 회사 사례 및 L3 직접 요청 차단, 세션 로그아웃, 잘못된 입력과 Origin, 비공개 파일 접근, 연구원 권한을 검사했습니다.
- **기존 Python 검사 28개 중 27개 통과, 1개 기본 경로 부재로 건너뜀.** 원래 테스트가 찾는 `work/rag-pilot/index.sqlite`는 보존 사본에 없었습니다. 별도 `evidence/check-legacy-index.py`로 실제 복사한 DB를 기존 Corpus에 전달하여 **51개 공고·167개 공개 문서·3,002개 L1 청크 및 모든 공고의 검색·권한·해시 검증을 통과**했습니다.
- **기존 JavaScript 검사 3개 스크립트 모두 통과.** HTTP 스트림 7개 묶음, 탐지 프로토콜 8개 사례, 저장 결과·취소·오래된 응답 차단·XSS·Unicode·인용·탐지 상태 구분을 검사했습니다. 모델 추론을 호출한 검사가 아닙니다.
- **브라우저 인수 검사 17개 시나리오 통과:** `evidence/browser-results.json`에 시나리오별 결과를 기록합니다. 1366×768과 1920×1080, 한국어 조합 중 Enter, 지역 건수, 단계 검색, 잘못된 금액 범위, 인용·구조·공고 탭, 파일 선택/제거, 문의 흐름, 로그인 다이빙과 화면 복귀, L2/L3 재생, 로그아웃, 연구원 조회를 포함합니다.
- 캐릭터 표정 시작 간격은 브라우저 MutationObserver로 관측했습니다. 목표 1,000ms이며 화면 갱신 프레임에 따른 약 한 프레임 편차가 있습니다. 입력 중 정지, 움직임 줄이기, 실제 커서 이동을 검사했습니다.
- 선별 사례 **100/100**에서 근거 청크 ID와 청크 텍스트 해시가 일치합니다. **100/100** 답변 SHA-256과 prediction 구절의 Unicode 범위·quote가 일치합니다. `evidence/replay-mapping.json`에 회사·등급·공고 대응을 남겼습니다.
- 네 표정은 서로 다른 SHA-256을 갖는 실제 RGBA PNG입니다. 모두 1363×1154이고 알파 범위 0–255입니다. 턱 하단은 불투명 영역 기준 y=1013–1016으로, 화면 표시 크기에서 약 1px 미만 차이입니다. `evidence/expression-assets.json` 참조.
- 초기 표정·궤도·커서 추적·로그인 다이빙을 실제 Chromium 화면으로 녹화했습니다. 최종 영상은 `evidence/astra-v12-demo.webm`입니다. DOM 상태만으로 동작 검증을 대체하지 않았습니다.

Windows 샌드박스가 Chromium 실행과 기존 테스트의 임시 디렉터리 접근을 처음 차단했습니다. 승인된 동일 테스트 재실행으로 검증했습니다. 브라우저 검증 중 발견한 표정 시계의 프레임 지연 누적과 긴 답변의 입력창 밀림을 수정했습니다. 테스트 자체의 지도 복귀·로그아웃·첫 프레임 대기 조건도 명확히 했습니다.

## 범위와 남은 연결 항목

1. **신규 생성·실시간 탐지·벡터 검색 미연결:** 1차에서 의도적으로 제외했습니다. 현재 E5/KLUE 추론 성공을 주장하지 않습니다. 기존 생성 서버 계약은 legacy-source에 보존되어 있으며 추후 UI 어댑터로 연결해야 합니다.
2. **첨부 분석 미연결:** PDF/HWP/HWPX/TXT 선택은 가능하지만 이번 서버는 파싱하지 않습니다. 모두 미지원 분석 상태를 표시하며 파일을 업로드·공개하지 않습니다.
3. **현재 지도 경계·주소 정규화 후속:** KOSTAT 2013 경계를 썼습니다. 기관명으로 확실히 확인한 지역만 매핑하고 40건은 미확인으로 남겼습니다. 사업 수행 지역과 자격 제한 지역은 원문 검토 대상입니다.
4. **평면 캐릭터의 한계:** 새 표정은 원본을 참고해 생성한 이미지로, 실제 3D 회전이나 원본 영상의 정확한 모션 캡처가 아닙니다. 도입부·커서 반응·전환 구간은 reference-*.png로 비교했고, 영상의 외부 고양이 배경은 옮기지 않았습니다.
5. **최종 승인 미완료 데이터:** 회사 자료의 pending/unreviewed/rag_ingest=false를 유지합니다. 선별 100건과 사람 검수 25문항·88개 구절은 서로 다른 집합이며 학습 내보내기나 승인 완료로 표시하지 않습니다.

## 검증 재실행

```powershell
python -m unittest test_server -v
python evidence/check-legacy-index.py
```

기존 소스 폴더 `legacy-source/demo-ui/spatial-poc`에서:

```powershell
python -m unittest test_integration test_l1_server -v
node --test test-rag-http.mjs test-rag-ux.mjs test-detection-http.mjs
```

브라우저 검사는 `evidence/acceptance.cjs`입니다. 현재 PC의 Playwright 런타임 경로를 명시했으므로 다른 PC에서는 해당 require 경로를 설치된 Playwright로 바꿔야 합니다. 앱 실행 자체는 Playwright가 필요 없습니다.
