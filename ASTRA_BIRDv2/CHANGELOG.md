# 변경 기록

## 파란새_v2 (bluebird-v2) — 새 UI / 2026-09-19

- 새 화면: 파랑새 첫 화면(등장 영상 → 살아있는 파랑새), 인기 HOT·마감 D-10 카드, 전체 공고 보러가기 알약 버튼.
- 로그인: 움직이는 배경, 6칸 비밀번호 카드. 로딩: 회사 배경 위 RAG 구축 연출과 실제 처리 단계.
- 본 화면: 노치형 사이드바, 크기 조절 두 창(저장 답변 질문 창 · 조건 필터 공고), 밝은 바탕과 3D 버튼, 마이페이지.
- 공고 탐색: 공고월·조건 언급·요건 시트 필터, 회사 조건 일치(맞춤 탐색, 일치순, 과정 화면), 목록 상태 복원.
- 서버: `/api/discover`(discovery.py) 추가. 인증·권한 API는 변경 없음.
- Windows `START_ASTRA_V3.cmd`, macOS/Linux `start_astra_v3.sh`, `실행방법.pdf`.
- 실행 ZIP(시연 데이터 포함)은 Release `bluebird-v2`의 첨부 파일로 제공.

## v1.0.1 — 소스 배포 보완 / 2026-09-17

- 소스 복제 시 누락되던 비밀값 없는 `.env.example`을 포함.
- V1 실행 ZIP과 시연 데이터는 v1.0.0의 동일한 파일을 사용.

## v1.0.0 — 대시보드 V1 / 2026-09-17

- 제작 프롬프트 1.2에 따른 현재 시연 완성본을 최초 기준 버전으로 확정.
- 게스트 홈, 4가지 표정, 기업 궤도와 로그인 다이빙.
- 단계형 공고 검색, 17개 시도 지도, 공고 DB 그래프.
- 회사별 로그인과 L2/L3 서버 권한 검사, 자료 조회.
- 저장 답변, 인용 근거, 검수 구절, 별도 연구원 조회.
- Windows x64 실행 ZIP과 버전 고정 시연 데이터 패키지 제공.
- 생성 모델·새 파일 분석은 미연결인 상태를 유지.
