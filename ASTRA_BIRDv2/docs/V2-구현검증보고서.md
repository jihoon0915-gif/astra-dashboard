## 실행

현재 작업 폴더의 `START_ASTRA.cmd` 실행. 이 PC에는 V1 배포본의 휴대용 Python을 `runtime/`에 복사해 두었다. 다른 PC에서 소스만 받으면 README의 Python·데이터 준비 절차가 필요하다. 실행 데이터는 기존 `ASTRA-demo-data-v1.zip`을 그대로 쓴다.

## 계정

기존 C01~C05의 `Cxx-1001`(L2), `Cxx-2001`(L2·L3)을 유지했다. 공개 전용 `Cxx-0001` 계정을 서버 시작 시 추가한다. 비밀번호는 전부 `000000`이다.

전체 비교는 **C01 / C01-2001**에만 지정했다. `demo-roles.json`에서 시연 담당자를 명시한다. API는 비교 허용 설정과 해당 회사 L3 권한을 모두 검사한다. L1/L2/다른 회사의 L3는 현재 전체 비교 API에서 403이다.

## 검증 결과

- 기존 통합 검사 5개 + 신규 권한/개인 기록 검사 2개 통과.
- 날짜 경계 검사 6개 통과: 결측, 잘못된 날짜, 한국시간 자정 전후, 마감 시각, 날짜만 있는 공고.
- 브라우저 11개 시나리오 통과. 홈·스크롤, 저장 답변·근거 경로, 키보드 폭 조절, 실패 로그인, 즐겨찾기, 비교 순서 공개, 로그아웃 후 비교 차단, 시연 날짜·동작 줄이기, 1920 화면, 125% CSS 확대, L1 계정.
- 추가 2개 시나리오 통과: 외부 Cesium 요청 차단 시 2D 대체, L2 회사 증빙 그래프. 브라우저 JS 오류 없음.
- 1366×768, 1920×1080 화면 캡처와 실제 흐름 녹화를 `evidence/v2/`에 보관했다. 확대 검사는 body CSS zoom 1.25로 수행했으며 실제 브라우저 메뉴 확대와 완전히 동일한 검사는 아니다.
- 최종 기록 변경 테스트는 8783 전용 검증 서버의 새 `browser-qa-*.sqlite`에서 수행했다. 기존 사용자의 개인 DB를 초기화하지 않는다.

## 확인이 필요한 부분과 명시적 대체 동작

1. **Cesium 실제 온라인 지도**: 유효한 ion 브라우저 토큰이 없어 온라인 타일·flyTo 결과는 실증하지 못했다. 설정에 토큰을 입력하면 연결한다. 토큰 미설정·외부 로딩 실패 시 2D 대체를 검증했다. 지도는 기관명 추정 지역이며 사업장 정밀 좌표가 아니다.
2. **비교 답변**: 실제 원문 청크 인용을 사용하는 결정적 작성 초안이다. 사람이 검토 완료한 모델 답변이 아니다. UI에 사람 검토 대기를 표시한다. 공고 참가 자격을 자동 확정하지 않는다.
3. **증빙 그래프**: 문서 보유·공고 요건·검토 대상 관계를 표시한다. 요건마다 어떤 개별 인력/실적/인증이 충족하는지 자동 판단하는 기능은 추가하지 않았다.
4. **생성·탐지**: 기존 저장 답변·저장 prediction과 사람 검수 표시를 유지한다. 생성 모델, 실시간 검색·탐지는 새로 연결하지 않았다.
5. **비밀번호 참고 영상**: Chromium과 Edge에서 영상 크기가 0으로 확인되어 장면을 읽지 못했다. 설치된 제한형 ffmpeg도 해당 컨테이너를 지원하지 않았다. 해당 영상의 동작은 추측해 복제하지 않았다.
6. **장면**: 이미지 레이어 기반 2.5D이며 자유 시점 3D 공간이 아니다. 폰트는 PC에 설치된 Georgia/Malgun Gothic 계열을 사용하며 참고 영상의 정확한 폰트는 아니다.
7. **영상 루프**: 무음 반복과 끝부분 280ms 이중 영상 크로스페이드를 적용했다. 동작 줄이기에서는 정지 포스터로 대체한다.
