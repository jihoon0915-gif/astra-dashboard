# ASTRA · 파란새 디자인 + 사용자 DB 통합본

## 실행

모델 포함판은 Python 3.11과 MODEL_SETUP.md의 의존성을 준비하고 `START_ASTRA_V3.cmd`를 실행하세요. 기본 포트는 8773이며 사용 중이면 다음 포트를 선택합니다. 처음 실행하면 공고/기업 자료와 사용자 DB를 로컬 private 폴더에 준비합니다.

## 로그인

- 회사 ID: `C01`
- 사용자명: `c01_bid_approver`
- 시연 비밀번호: `000000`
- 로그인 화면에서 회사 → 역할·사용자명 드롭다운을 선택하세요. “비밀번호 채우기”는 공통 시연 비밀번호를 입력하며 로그인 버튼으로 진행합니다. 비활성 계정은 선택할 수 없습니다.
- 전체 계정표: `user-db/DEMO_LOGIN_ACCOUNTS.csv`

새 사용자 DB의 25개 계정을 사용합니다. 활성 20개, 비활성 5개입니다. 이전 C01-2001 / 000000 계정은 사용하지 않습니다. 기본 기준일은 2026-05-11입니다.

## 권한

viewer는 공개 L1, bid_analyst는 자사 L1/L2, cost_analyst는 자사 L1/L2와 허용된 L3 원가/견적, bid_approver는 자사 L1/L2/L3를 조회합니다. 문서 자체의 allowed_roles 제한도 함께 적용합니다. 비활성 계정 또는 소속 비활성 계정은 로그인과 내부 자료 접근을 거절합니다.

서버 세션은 user_id와 만료시간을 저장하며 각 요청마다 DB의 계정/소속/역할을 다시 조회합니다. 브라우저가 보낸 역할이나 tenant 값으로 권한을 변경하지 않습니다. 로그인된 화면도 탭 복귀 및 15초 간격으로 상태를 다시 확인합니다.

사용자 DB 원본은 `user-db/users.demo.sqlite3`, 실행 시 사용하는 DB는 `private/users.demo.sqlite3`입니다. 기존 실행 DB는 자동 덮어쓰지 않습니다. 원본 ZIP의 DB/JSON/CSV/TXT는 수정 없이 포함했습니다. 마이페이지는 DB의 display_name을 표시합니다. 개인 기록은 tenant_id와 user_id로 분리하며 예전 사번 기록은 보존하되 자동 이관하지 않습니다.

권한별 비교는 기존 시연 담당자에 대응하는 C01 입찰 승인자에게 제공됩니다. 연구원 조회는 기존 별도 연구원 키와 자사 L3 권한이 필요합니다.

## 검증

`python -m unittest test_user_db -v`

25개 계정, 20개 활성 계정의 회사별 문서 직접 접근, 계정/소속 비활성화, 로그인 후 역할 변경, 문서 종류 제한, 위조 권한 입력, 개인 기록 분리, 저장 답변 해시, 비교 권한, DB 비공개 경계를 검사합니다.

`node test_bluebird.mjs` / `node test_dates.mjs`

기존 test_server.py/test_v2.py/test_discovery.py는 이전 사번 인증의 보존된 테스트이며 새 로그인 계약에는 위 test_user_db.py를 사용합니다. 예전 evidence와 INTEGRATION.md의 과거 계정 수/검증 기록은 이전 버전 기록입니다.

## 유지한 내용

파란새 화면 디자인, 맞춤 탐색 세로 단계 및 직선 그래프, 마이페이지 문서 영역 개선, 공고 51건, 회사 문서 41개와 저장 사례 111건을 유지합니다. 직접 입력한 질문은 선택한 로컬 Qwen3 8B / 4B / 1.7B Q4_K_M으로 생성하고, 새 ASTRA BGE-M3 토큰 분류 모델로 검사합니다. 예시 질문 버튼은 기존 저장 답변을 보여줍니다. 지도·공고 DB 관계도·근거 경로·연구원 전용 화면의 전체 디자인 이식은 이전과 같이 남아 있습니다.

모델 포함판의 실행 조건과 처리 방식은 [MODEL_SETUP.md](MODEL_SETUP.md)를 참고하세요. 공고를 선택하고 질문을 입력하면 생성 → 검사 순서로 실행하며, 의심 구절은 노란색으로 표시합니다. 검사 실패는 미검증으로 표시합니다.

전달 ZIP에는 실행 중 생성된 연구원 키, 개인 기록, 테스트용 세션이 포함되지 않습니다. 모든 사용자/기업 데이터는 로컬 시연용 합성 자료입니다.

사용자 DB 25개 계정의 비밀번호는 모두 000000으로 동일함을 각 계정의 PBKDF2 해시로 확인했습니다. 로그인 드롭다운은 합성 시연 계정의 표시 필드만 반환하며 비밀번호 해시·salt는 반환하지 않습니다.

2026-09-22 추가 적용: 팀원 제공 검색 함수로 공고와 회사 근거를 분리 선별합니다. Qwen 문맥은 8,192토큰이며 역할에 허용된 L2·L3 자료도 생성·탐지의 공통 근거로 사용합니다. 기존 저장 답변에는 소급 적용되지 않으므로 새 질문으로 확인하세요. 이번 최신 배포 ZIP에는 회사 근거 분리 검색과 모델 선택 기능이 포함됩니다.
