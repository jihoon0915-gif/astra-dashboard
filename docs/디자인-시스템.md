# 디자인 시스템과 참고 관찰

2026-09-18 https://weevolveit.com/ 에 직접 접속했습니다. 웹 문서와 실제 브라우저 화면을 확인했습니다.

## 직접 확인

- 최초 화면: 거의 검은 바탕, 작은 점 격자, 흰 점으로 이루어진 구체, 약한 분홍 강조, 넓은 여백.
- 헤더: 가장자리에서 떨어진 캡슐형 경계. 작은 모노스페이스 메뉴와 브랜드.
- MORE 메뉴 클릭: 헤더 아래의 어두운 둥근 드롭다운.
- 아래 스크롤: 후기 영역에서 밝은 프레임워크 영역으로 전환. 매우 큰 모노스페이스 제목과 단계형 설명.
- 원본 모션의 프레임별 타이밍과 카드 hover의 전체 동작은 정밀 측정하지 않았습니다. 확인하지 않은 효과를 동일하게 복제했다고 주장하지 않습니다.

입자는 실제 문서 수나 지구 지도가 아닌 장식입니다. Canvas 2D로 외부 엔진 의존을 피했습니다. 한 세션에 한 번 수렴하고, 재진입은 수렴을 생략합니다. 탭 숨김·화면 밖에서는 프레임 요청을 중단합니다. reduced-motion 및 끄기는 정적으로 표시합니다. Canvas 사용 실패 시 CSS 구체를 사용합니다.

후보 그래프의 펼침은 이미 응답받은 결과의 설명용 표시입니다. 서버가 보내는 완료 이벤트와 참가 자격 자동 판정 미실행을 별도로 표시합니다. 후보 목록은 연출을 기다리지 않습니다. 경로 재생도 저장 관계 재생이며 실제 검색 로그가 아닙니다.

원본의 고객사 로고·성과·후기·연혁·상용 자산을 복사하지 않았습니다. 기존 ASTRA의 얼굴·고양이·숲·로그인 영상·다이빙 자산을 public에 포함하거나 요청하지 않습니다.

JetBrains Mono 추가 다운로드 대신 Geist Mono로 영문 메타를 통일했습니다. 한국어 본문 자간을 영문처럼 늘리지 않았습니다. hover·focus 경계를 제공하며 색 외에 등급/유형 문자를 함께 표시합니다.
