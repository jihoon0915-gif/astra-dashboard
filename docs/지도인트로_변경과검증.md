# 지도 인트로 개정 — 2026-09-18

사용자의 후속 요청에 따라 질문 화면 이전에 국내 공고 지도를 배치했습니다. WeevolveIT 사이트를 직접 열어 확인하고, 사용자가 첨부한 검정/흰색 유기적 경계 이미지를 참고했습니다.

## 구현

- 최초 문서 진입 시 000→100% 로딩. 공고 API, 지도, 서체 준비, 화면 구성 완료에 따라 가중 진행률이 증가합니다. 숫자는 완료된 단계까지만 부드럽게 따라갑니다. 네트워크 바이트 백분율은 아닙니다.
- 로컬 GeoJSON 기반 정지 대한민국 지도. 외부 지도 API나 토큰이 필요하지 않습니다.
- 기관명으로 지역이 분류된 공고 11건을 8개 지역 중심에 묶어 표시합니다. 정확한 발주기관 주소나 사업 수행 위치가 아닙니다. 나머지 40건은 지역 미확인 목록에 있습니다.
- 공고 불빛은 2초 주기로 점진적으로 밝아졌다 어두워집니다. 일시정지 버튼, 동작 줄이기 설정, 화면 밖 애니메이션 정지를 지원합니다.
- 위치 또는 지역 버튼 선택 시 지도 영역 확대와 실제 공고 카드 목록 표시. 전국 복귀, 미확인 목록, 공고 상세 작업 공간 연결.
- 일반 스크롤로 불규칙한 흰색 SVG 경계가 올라오고 확장되며 흰 질문 입력 화면으로 이어집니다. 스크롤을 가로채지 않습니다.
- 질문 화면의 기존 검색·저장 질문·회사 맞춤 탐색 연결을 유지합니다. 자유 생성형 챗봇을 새로 연결한 것은 아닙니다.

## 녹화본·Paperlogy 후속 개정

첨부된 9.13초 녹화본에서 프레임을 추출하여 검정→흰색 전환을 확인했습니다. 기존 장식 경계 대신 sticky 전환 화면과 스크롤 위치에 직접 연결된 SVG 침식 경계를 적용했습니다. 스크롤을 되돌리면 같은 위치로 복원되고 멈추면 진행도 멈춥니다. 숨겨진 질문 입력은 전환 완료에 가까워지기 전까지 inert 처리합니다.

상단 메뉴 → 소개 문구 → 지도 → 지역 요약 → 하단 안내를 180ms 간격으로 등장시킵니다. 로딩이 끝난 뒤 시작하며 동작 줄이기 설정에서는 즉시 표시합니다. 경로 이탈 시 이벤트·프레임·타이머를 해제합니다.

사용자 제공 Paperlogy TTF 9개를 WOFF2로 변환했습니다. 본문 400, 설명 300, 메뉴 500, 주요 제목 600/700을 사용하며 숫자·영문 기술 표시는 기존 Geist를 유지합니다. 원본 메타데이터와 SIL OFL을 fonts 폴더에 포함했습니다. 기본 400/700 서체를 미리 로드합니다.

브라우저 computed style에서 Paperlogy 적용과 등장 지연 0/180/360/540/720ms 확인. 전환 진행률 0.583 → 역방향 스크롤 0.399 확인. 질문 영역 전환 후 inert 해제 확인. 기존 렌더링 8개와 날짜 경계 6개 검사 통과.


## 항목별 스크롤 스냅 개정

홈에 브라우저 기본 세로 스냅을 적용했습니다. 지도, 전환 완료된 질문 화면, 데이터 요약, 기능 소개, 이용 흐름, HOT 공고, 전체 공고 및 푸터가 정착 지점입니다. 항목 통과를 줄이는 scroll-snap-stop: always를 사용합니다. 휠/터치 이벤트를 강제로 가로채지 않습니다. 화면보다 긴 항목 안에서는 스크롤을 허용하며 공고 상세 등 다른 경로로 이동하면 홈 스냅을 해제합니다. 동작 줄이기에서는 짧아진 질문 화면의 시작에 맞춥니다.

브라우저 확인: 질문 화면 정착 오차 0.19px, 전환 진행률 1.000. 작은 스크롤 후 항목 중간 대신 질문 위치에 정착, 추가 스크롤 후 데이터 요약 시작에 정착. 역방향 이동 확인. 전체 공고 목록 내부 418px 이동 후 목록 상단으로 끌려가지 않음. 공고 작업 공간 진입 시 scroll-snap-type: none 확인.
